# Pawgress 用語集（ユビキタス言語）

ドキュメント・コードを通じて一貫して使う Pawgress 固有の用語です。ここにない一般的な言葉（タスクの追加、ボタン等）は、通常の日本語で表記します。

## 画面名

次の5語は、画面・ルートを通じて一貫して使う固有名詞として、翻訳せずそのまま用います（History のみ画面上の表示が「記録」になります）。

| 用語 | 画面上の表示 |
| --- | --- |
| Today | Today |
| Inbox | Inbox |
| Review | Review |
| History | 記録 |
| Settings | Settings |

## Today のライフサイクル

Today 画面が取りうる4つの状態の総称です。1日のうちに次のいずれかを経ます。

| 状態 | 意味 |
| --- | --- |
| 準備中 | Today 未設定。繰り越し・Inbox・新規作成からタスクを選ぶ |
| 実行中 | Today 開始後、タスクに取り組んでいる |
| 休み | その日は Today を開始せず、休みとして記録した |
| 完了 | Review の「1日を終える」が成功した |

休みと完了は同じ日のうちに限り取り消せ、取り消すとそれぞれ準備中・実行中へ戻ります。

## その他のドメイン用語

| 用語 | 意味 |
| --- | --- |
| 繰り越し | 前日に完了しなかったタスクのうち、今日も取り組むか選べる候補。選ばれなければ Inbox へ戻り、特別な保存場所には残らない |
| 振り分け | Review で未完了タスクに対して行う「明日に持ち越す」か「Inbox へ戻す」かの選択 |
